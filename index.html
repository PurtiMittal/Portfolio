Customer Segmentation & Interest Analysis

End-to-end SQL analysis uncovering trends, volatility patterns and customer behavior insights for Fresh Segments - a company tracking online audience interaction.

MS SQL Server
Data Cleaning
Data Validation
GitHub

What I Worked Through

  • Started with a raw interest_metrics table that needed fixing before any analysis could happen.
  • Converted month_year to DATE (1st day of the corresponding month).
  • Identified and removed 1194 null records after taking a backup.
  • Resolved 188 apparent date discrepancies that turned out to be a formatting artefact, not real errors.
  • Built a quality filter using cumulative percentage analysis to identify that interests present for 6+ months account for 90%+ of the dataset.
  • Profiled the customer segment using composition and index values.
  • Identified the most consistent and most volatile interests.
  • Built a 3-month rolling average output with prior month context matching Danny's expected output exactly.

Technical Highlights

  • Multi-level CTEs to keep complex logic readable across all 4 sections.
  • Used DENSE_RANK() for monthly rankings.
  • Used FIRST_VALUE() to retrieve boundary month_year values without extra joins.
  • Used LAG() for rolling prior-month context.
  • Used STDEV() for volatility measurement.
  • Used SUM() OVER() for cumulative percentage analysis.
  • Used ROWS BETWEEN 2 PRECEDING AND CURRENT ROW for rolling averages.
  • Used DECLARE to avoid unnecessary nested subqueries.
  • Used RANK() instead of ROW_NUMBER() wherever ties needed to be retained.

Key Finding

Detected a 70%+ drop in top-tier engagement from late 2018 to mid 2019 - indicating a structural decline rather than seasonal fluctuation.
